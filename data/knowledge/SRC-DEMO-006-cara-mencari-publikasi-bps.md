# Panduan Mencari Publikasi dan Data BPS

## Kanal Akses Resmi Data BPS
Masyarakat, mahasiswa, akademisi, dan pembuat kebijakan dapat mengakses data statistik resmi BPS melalui kanal-kanal berikut:

1. **Website Resmi BPS (bps.go.id):**
   - Masuk ke portal `bps.go.id` untuk data tingkat nasional, atau `[namadaerah].bps.go.id` (contoh: `jabar.bps.go.id`, `surabaya.bps.go.id`) untuk data tingkat daerah.
   - Menu **Publikasi:** Berisi ribuan buku publikasi dalam format PDF yang dapat diunduh secara gratis setelah registrasi singkat.
   - Menu **Tabel Dinamis / Data Statistik:** Memungkinkan pengguna mengunduh tabel data kustom menurut variabel, tahun, dan wilayah dalam format Excel atau CSV.
   - Menu **Berita Resmi Statistik (BRS):** Rilis resmi bulanan/berkala mengenai indikator strategis (Inflasi, Pertumbuhan Ekonomi, Ekspor-Impor, Pariwisata, Tenaga Kerja).

2. **Aplikasi Mobile "AllStat BPS":**
   - Tersedia di Google Play Store dan Apple App Store untuk akses cepat tabel data dan publikasi di perangkat mobile.

3. **Portal BPS WebAPI (webapi.bps.go.id):**
   - Layanan API RESTful untuk pengembang aplikasi dan integrasi sistem.

4. **Pelayanan Statistik Terpadu (PST):**
   - Layanan tatap muka di kantor BPS Pusat, BPS Provinsi, maupun BPS Kabupaten/Kota.
