# User Stories

> **Project:** BPS AI Assistant — Web Demo  
> **Target:** Demo publik tanpa login  
> **Provider:** LimitRouter (`https://limitrouter.com/v1`)  
> **Rule:** API key server-side only.


## Masyarakat
- Saya ingin bertanya tanpa membuat akun.
- Saya ingin bahasa yang mudah dipahami.
- Saya ingin melihat sumber.
- Saya ingin AI meminta klarifikasi bila wilayah/tahun belum jelas.
- Saya ingin diberi tahu jika informasi tidak ditemukan.
- Saya ingin membuka sumber BPS.
- Saya ingin memberi feedback.

## Ketua Tim
- Saya ingin melihat bentuk produk jika sudah jadi.
- Saya ingin melihat bahwa jawaban tidak hanya berasal dari hafalan LLM.
- Saya ingin melihat kontrol scope.
- Saya ingin memahami bahwa model/provider dapat diganti.
