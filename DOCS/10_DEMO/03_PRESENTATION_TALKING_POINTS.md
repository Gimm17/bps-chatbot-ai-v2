# Talking Points

> **Project:** BPS AI Assistant — Web Demo  
> **Provider:** LimitRouter (`https://limitrouter.com/v1`)  
> **Rule:** provider key hanya server-side.


**LLM**  
> Kita tidak melatih AI dari nol. Kita memakai foundation model melalui gateway.

**RAG**  
> RAG membuat AI mencari sumber BPS sebelum menjawab.

**LimitRouter**  
> Dipakai sebagai provider demo, tetapi frontend tidak dikunci ke provider.

**No login**  
> User tidak login, tetapi backend tetap punya rate-limit dan security.

**Fine-tuning**  
> Bukan syarat demo; hanya dilakukan jika benchmark menunjukkan perlu.

**Target akhir**  
> Produk akhirnya adalah platform BPS AI, bukan sekadar satu model.
