# UI/UX Specification

> **Project:** BPS AI Assistant — Web Demo  
> **Provider:** LimitRouter (`https://limitrouter.com/v1`)  
> **Rule:** provider key hanya server-side.


## Direction
- professional;
- clean;
- trustworthy;
- source-oriented;
- tidak terlalu futuristik;
- hindari efek AI berlebihan.

Gunakan brand BPS resmi hanya jika guideline/asset tersedia.

## Main
Header:
- BPS AI Assistant
- Prototype/Demo badge

Welcome:
- headline
- scope
- 4 suggested prompts

Chat:
- user bubble
- AI message
- source cards
- copy
- feedback

Composer:
- multiline
- send
- Enter/Shift+Enter

## States
- empty
- sending
- retrieving
- generating
- answered
- clarification
- no_evidence
- out_of_scope
- rate_limited
- provider_error

## Mobile
Target comfortable at 360–430px width.

## Accessibility
Keyboard, focus visible, semantic buttons, descriptive links, no token-by-token screen-reader spam.
