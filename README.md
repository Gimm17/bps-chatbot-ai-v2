## 🌟 Tentang BPS AI Assistant

**BPS AI Assistant** adalah asisten kecerdasan buatan (AI) publik resmi yang dirancang untuk memudahkan masyarakat, akademisi, peneliti, jurnalis, dan pelaku usaha dalam menanyakan dan menemukan **data statistik, konsep, metodologi, dan publikasi resmi Badan Pusat Statistik (BPS) Republik Indonesia**.

Chatbot ini terintegrasi secara **real-time dengan portal data BPS WebAPI** mencakup BPS Pusat dan seluruh **549 BPS Provinsi dan Kabupaten/Kota** di Indonesia.

---

## ✨ Fitur Unggulan

- 🏛️ **Terhubung Langsung ke BPS WebAPI:** Menarik data indikator strategis nasional dan daerah secara *real-time* (Inflasi, Pertumbuhan Ekonomi, Kemiskinan, Pengangguran/TPT, Kependudukan, dll).
- 📚 **Katalog Publikasi & Dokumen PDF:** Menemukan buku publikasi resmi BPS dan menyediakan tautan langsung ke portal resmi serta link unduh file PDF asli.
- 🗺️ **Cakupan Multi-Daerah (549 Wilayah):** Mampu mengenali pertanyaan spesifik untuk seluruh provinsi dan kabupaten/kota di Indonesia (misal: *Sulawesi Tengah, Jawa Barat, Kota Palu, Surabaya*).
- 🔗 **Rujukan Terverifikasi (Source Trust):** Setiap jawaban dilengkapi kartu sumber rujukan resmi yang dapat diklik langsung ke portal BPS dan SIRuSa (Sistem Informasi Rujukan Statistik).
- 💬 **Tanpa Perlu Registrasi:** Siapapun dapat langsung menggunakan layanan ini secara gratis dan instan.
- 🔌 **Widget Embeddable:** Dapat dipasang dengan mudah sebagai tombol mengambang (*floating widget*) di portal web BPS manapun.

## 💡 Contoh Pertanyaan yang Bisa Diajukan

Anda dapat menanyakan berbagai topik statistik, seperti:

| Kategori | Contoh Pertanyaan |
|---|---|
| **Definisi & Konsep** | *"Apa itu inflasi dan bagaimana BPS menghitungnya?"* |
| **Data Makroekonomi** | *"Berapa pertumbuhan ekonomi Indonesia saat ini?"* |
| **Kependudukan Daerah** | *"Data penduduk Sulawesi Tengah tahun 2026"* |
| **Buku Publikasi** | *"Tampilkan publikasi kependudukan Sulawesi Tengah 2025"* |
| **Ketenagakerjaan** | *"Apa itu Tingkat Pengangguran Terbuka (TPT)?"* |
| **Layanan BPS** | *"Bagaimana cara mengakses layanan Pelayanan Statistik Terpadu (PST)?"* |

## 🔌 Cara Pasang Widget di Website Resmi

Untuk menyematkan BPS AI Assistant sebagai tombol toggle **"💬 Tanya BPS"** pada website portal BPS atau instansi terkait, cukup tambahkan satu baris script berikut sebelum tag `</body>`:

```html
<!-- BPS AI Assistant Embed Widget -->
<script src="https://bps-chatbot-v2.pinnhost.my.id/build/assets/embed.js" defer></script>
```

Tombol asisten cerdas akan otomatis muncul di sudut kanan bawah halaman web Anda.
